# Smart Retail Promotions Hub - Frontend

This is the frontend for the Smart Retail Promotions Hub, a web application for managing marketing campaigns. It is built with React, Vite, and Tailwind CSS.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have Node.js and npm installed on your machine.

### Installing

1. Clone the repo:
   ```sh
   git clone https://github.com/SrinivasSurisetti/Smart-Retail-Promotions-Hub.git
   ```
2. Navigate to the `frontend` directory:
   ```sh
   cd front_end/frontend
   ```
3. Install NPM packages:
   ```sh
   npm install
   ```

### Running the Application

To run the app in development mode, run the following command from the `frontend` directory:

```sh
npm run dev
```

This will start the Vite development server, and you can view the application at `http://localhost:5173` (or another port if 5173 is in use).

## Building for Production

To create a production build, run:

```sh
npm run build
```

This will create a `dist` folder with the optimized and minified files for deployment.

## Built With

- [React](https://reactjs.org/) - The web framework used
- [Vite](https://vitejs.dev/) - Frontend tooling
- [Tailwind CSS](https://tailwindcss.com/) - For styling
